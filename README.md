# Have You Tried Turning It Off?

[![make.fun](https://make.fun/badge.svg)](https://make.fun/c/u-motasimfuad-have-you-tried-turning-it-off-154a938b)

One funny line a hopeless tech support agent gives a desperate customer — an entry for the [make.fun competition](https://make.fun/c/u-motasimfuad-have-you-tried-turning-it-off-154a938b).

## The line

> Great news — I have escalated your ticket to a team that no longer exists, so technically you are now our top priority.

119 characters. Cheerful uselessness: the escalation goes nowhere, and somehow that makes the customer the top priority.

## How it works

`main.py` (Python standard library only) writes the line to `/output/entry.txt`.
